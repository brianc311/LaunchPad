# 3PAR Array GUI Port 8443 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** When Admin URL is empty, Open GUI for HPE 3PAR cards uses `https://{host}:8443` on the Arrays side rail and FC Open GUI; Primera and other profiles keep `https://{host}`.

**Architecture:** Extend shared `resolve_gui_url(url, host, device_profile="")` to append `:8443` when URL is empty, host has no port, and `device_profile` is in `HP_3PAR_PROFILES`. Pass `card.device_profile` from `rail_gui_url` and `open_card_gui`. Prefer Admin URL unchanged.

**Tech Stack:** Python, pytest, existing `HP_3PAR_PROFILES`, CustomTkinter dashboard rail, webbrowser.

**Spec:** `docs/superpowers/specs/2026-08-10-3par-gui-port-8443-design.md`

## Global Constraints

- APP_VERSION is currently `1.6.145`; bump to `1.6.146` in the wiring/version task.
- Only `HP_3PAR_PROFILES` (`hpe_3par_8200`, `hpe_3par_8400`, `hpe_3par_8450`) get auto-`:8443`.
- `hpe_primera_600` must **not** get auto-`:8443`.
- Prefer Admin URL when non-empty (normalize scheme only).
- If host already ends with `:<digits>`, do not add another `:8443`.
- Same rule for Arrays rail and FC Open GUI via shared helper.
- Do not seed Admin URL on save; do not change SSH Connect; do not change Volume Find / Snapcopy links.
- Windows PowerShell commits (`git commit -m "..."`); commit at each task’s commit step.
- Prefer TDD: failing test → implement → pass → commit.
- Do not commit `.superpowers/sdd*` scratch or install zips.

```python
_HOST_HAS_PORT_RE = re.compile(r":\d+$")


def resolve_gui_url(
    url: str = "",
    host: str = "",
    device_profile: str = "",
) -> str:
    """Prefer Admin GUI URL; else host, with :8443 for HPE 3PAR profiles."""
    preferred = normalize_gui_url(url)
    if preferred:
        return preferred
    host_s = str(host or "").strip()
    if not host_s:
        return ""
    profile = str(device_profile or "").strip()
    if profile in HP_3PAR_PROFILES and not _HOST_HAS_PORT_RE.search(host_s):
        return f"https://{host_s}:8443"
    return normalize_gui_url(host_s)
```

Do not change `normalize_gui_url`.
